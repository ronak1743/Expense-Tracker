# 💰 Expense Tracker App

An Android application built to help users **log, track, and manage their daily expenses** with ease.

Built using **Java** and **Firebase**, it ensures your financial data stays safe, secure, and accessible — even if you reinstall the app!

---

## 🚀 Features

* 🧾 **Add Expenses:** Record every transaction with **amount, date, time**, and an optional **note**.
* 🔐 **User Authentication:** Secure sign-in and sign-up using **Firebase Authentication** ensures your data is private and linked to your account.
* ☁️ **Cloud Storage (Firebase Realtime Database):** Your expense data is safely stored online, accessible anytime, even after reinstalling the app.
* 📊 **Expense Summary:** View total **cash inflows** and **outflows** at a glance.
* 🧘‍♂️ **Simple & Clean UI:** Minimal and intuitive interface for a smooth user experience.

## 📱 Setup Instructions

### 1. Clone the Repository

```bash
git clone [https://github.com/ronak1743/Expense-Tracker.git](https://github.com/ronak1743/Expense-Tracker.git)
cd Expense-Tracker
```

### 2. Open in Android Studio

1. Launch Android Studio.
2.  Click ` File` →` Open...` and select the project folder.
   
### 3. Configure Firebase

1. Connect your project to Firebase using the Tools → Firebase menu.

2. Ensure you Enable Firebase Authentication and Realtime Database within your Firebase console for this project to function correctly.

### 4. Build and Run

1. Click the ▶️ Run button (or Run → Run 'app') to build and install the app on your emulator or connected device.
